# Cybersecurity Threat Analysis — Capstone Project

## Project Overview

This project is a multi-part cybersecurity capstone consisting of scenario-based security exercises covering **cloud security, communication security, malware and endpoint security, vulnerability management, and payment application threat modeling**.

The project focuses on identifying security risks, analyzing potential attack scenarios, evaluating security weaknesses, and developing appropriate mitigation approaches across different cybersecurity environments.

## Objective

To analyze different cybersecurity scenarios by identifying potential threats and vulnerabilities, evaluating their impact, assessing relevant security controls, and developing appropriate mitigation strategies to improve overall security and resilience.

## Capstone Approach

The capstone consists of five cybersecurity-focused scenarios:

1. **Cloud Security** — Analyzing cloud security risks such as misconfigurations, identity and access management, and least-privilege requirements.
2. **Communication Security** — Examining phishing, social engineering, malicious links and attachments, and human-related security risks.
3. **Malware & Endpoint Security** — Analyzing malware entry points and evaluating endpoint security controls and defensive measures.
4. **Vulnerability Management** — Assessing unpatched vulnerabilities, exploitation risks, vulnerability prioritization, and mitigation approaches.
5. **Payment Application Threat Modeling** — Identifying assets, entry points, trust boundaries, and potential threats within an online payment application.

## What I Learned

Through these scenarios, I developed a broader understanding of how cybersecurity risks can differ across **cloud environments, communication systems, endpoints, vulnerable applications, and payment systems**.

Key areas of learning included:

- Identifying security weaknesses and potential attack paths.
- Understanding how misconfigurations and excessive privileges can increase risk.
- Recognizing phishing and social engineering as significant human-focused threats.
- Understanding common malware entry points and endpoint security controls.
- Prioritizing vulnerabilities based on risk and potential impact.
- Applying threat modeling concepts to identify potential threats.
- Understanding how security controls such as authentication, segmentation, input validation, and cryptographic protection can reduce risk.

## Conclusion

This capstone provided scenario-based exposure to multiple areas of cybersecurity. By analyzing different security problems and developing mitigation approaches, the project strengthened my understanding of **threat identification, vulnerability assessment, security controls, and risk mitigation** across different environments.
